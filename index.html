    Perbarui KiKo

    Hubungkan base untuk mengecek versi firmware.

    Biarkan HP di dudukan dan baterai di atas 50 % (atau charger tercolok). Lama +-1–2 menit. Kalau ada yang gagal, KiKo kembali ke versi lama sendiri.

    Aplikasi

    Buka dari GitHub Pages di Chrome untuk memasang KiKo sebagai aplikasi (atau menu ⋮ → Instal aplikasi).

    Pelacakan wajah

    Mati.

    Gambar kamera diproses di HP saja dan tidak dikirim ke mana pun. Hanya jalan di versi GitHub Pages, tidak di link artifact.

    Ngobrol (AI)

    Isi alamat Worker untuk memunculkan tombol mikrofon.

    Yang didengar KiKo (10 terakhir)

      Ketuk tombol mikrofon lalu bicara. Pengenal suara Chrome mengirim suara ke Google untuk diubah jadi teks; teksnya dikirim ke Worker Anda lalu ke model AI Cloudflare (gratis).

      Menari ikut musik

      Mati.

      Suara diolah di HP saja, tidak direkam dan tidak dikirim. Selama mode ini nyala, dengar otomatis (ngobrol) istirahat; tombol mikrofon tetap bisa dipakai. Tidak menari di jam mode malam.

      Jam & pengingat

        Telepon & WhatsApp

          Bilang: "telepon Mama", "WA Mama", "kirim pesan ke Mama aku pulang telat". KiKo selalu menampilkan tombol hijau dulu; telepon atau pesan baru jalan setelah Anda mengetuknya. Nomor hanya disimpan di HP ini, tidak dikirim ke AI.

          Pesan masuk

          KiKo Notif (aplikasi Android) membaca notifikasi pesan dari aplikasi apa pun (WhatsApp, SMS, Telegram, …) dan memberikannya ke KiKo hanya di dalam HP (127.0.0.1); tidak ada yang dikirim ke internet. Gelembung muncul beberapa detik di bawah tanpa menutupi wajah.
